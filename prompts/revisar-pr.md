---
description: Revisar un PR antes de mergear
---

Revisa el código del PR actual siguiendo el protocolo del Revisor (agents/05-revisor.md):

1. Primero verificar que CI está en verde
2. Revisar en orden: funcional → seguridad → errores → performance → legibilidad → tests
3. Formato de output: 🔴 CRÍTICO / 🟡 IMPORTANTE / 🟢 SUGERENCIA
4. Veredicto final: aprobado o bloqueado
